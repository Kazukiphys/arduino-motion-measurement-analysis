# Arduino Motion Measurement Analysis

Arduino UNO R4 と HC-SR04 超音波センサーで距離・速度を測定し、ブラウザー上でグラフ表示・解析するプロジェクトです。

## Features

- x-t グラフと v-t グラフの切り替え
- 複数実験の記録、表示切り替え、重ね合わせ
- グラフ範囲の移動と範囲指定
- 測定値が縦軸の範囲を超えたときの自動拡大
- 選択範囲の近似直線と R² の表示
- v-t グラフでの変位（速度の時間積分）の表示
- 測定値の CSV 出力

## Hardware

- Arduino UNO R4
- HC-SR04

| HC-SR04 | Arduino UNO R4 |
| --- | --- |
| VCC | 5V |
| Trig | D4 |
| Echo | D3 |
| GND | GND |

## Requirements

- Arduino IDE
- Web Serial API に対応したデスクトップ版 Google Chrome または Microsoft Edge

## Getting Started

1. `ultrasonic_sensor_HC-SR04/ultrasonic_sensor_HC-SR04.ino` を Arduino IDE で開き、Arduino UNO R4 に書き込みます。
2. ブラウザーで `index.html` を開きます。
3. 初期設定の 30 Hz で測定する場合は「測定開始」を押し、Arduino のシリアルポートを選択します。レートを変更する場合は、希望する数値を入力して「設定」を押すと、そのレートで測定を開始します。
4. 記録を一時停止した後、同じレートで別の実験を始めるには「次の実験を開始」を押します。
5. 記録を終えたら CSV を書き出します。

シリアル通信は 9600 baud です。サンプリングレートの初期値は 30 Hz です。通常は「測定開始」を押してください。レートを変更するときだけ、画面の「サンプリングレート」欄で 1〜100 Hz の目標値を指定して「設定」を押します。Arduinoに設定を送った後、そのレートで測定を開始します。センサーのエコー待ち時間などにより実測値は目標値より低くなることがあります。実測値は「実験条件」に表示されます。

一時停止後は、接続を切らずに「設定」からレートを変更できます。設定確認が返らない場合は送信を再試行し、それでも確認できない場合はエラーを表示します。

x-t グラフの縦軸は初期状態で 0〜1.0 m です。測定値が縦軸の範囲を超えた場合は自動的に範囲を拡大します。v-t グラフも同様に調整します。横軸は従来どおり時間範囲の移動・変更が可能です。

範囲指定時の面積の塗りつぶしは v-t グラフのみ表示します。v-t グラフでは速度 0 の位置に黒い横線と目盛りを表示し、範囲を移動・変更しても 0 を含むようにします。

v-t グラフは測定点を直線で結び、選択範囲のグラフと速度 0 の線の間を実験の色で塗りつぶします。変位はその範囲を台形公式で積分し、速度 0 より上を正、下を負として合計します。

画面からレートを変更するには、上記のスケッチを Arduino UNO R4 に書き込んでください。ポートを選択できない場合は、Arduino IDE のシリアルモニターなど、同じポートを使用するアプリケーションを閉じてください。

## Measurement Data

Arduino はサンプルごとに、次の順でカンマ区切りの値を出力します。

```text
time_s,distance_cm,velocity_m_s
```

距離は平滑化したセンサーと物体間の距離です。総移動距離ではありません。CSV では距離をメートルに換算して出力します。

時刻は Arduino が各測定開始時に取得した `micros()` に基づき、実験の最初の測定を 0 秒として、マイクロ秒単位（秒の小数第6位まで）で画面と CSV に表示します。設定レートから作る理論時刻ではありません。表示桁数は測定精度を保証するものではありません。新しい時刻形式を使うには、スケッチを Arduino に書き直してください。古いスケッチの時刻は送信時に丸められているため、失われた桁は復元できません。距離・速度の出力桁数は従来どおりです。

CSV は実験ごとに時間・距離・速度の3列を横に並べ、各実験の測定順に行を揃えます。測定点数が異なる場合、データがない部分は空欄になります。行は同じ測定時刻を意味するものではありません。

```text
実験1_time[s],実験1_distance[m],実験1_velocity[m/s],実験2_time[s],実験2_distance[m],実験2_velocity[m/s]
0.000000,0.2500,0.1200,0.000000,0.3000,0.0800
0.033350,0.2600,0.1300,,,
```
